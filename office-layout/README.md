# 나르카 사무실 배치도 (초안)

평면도 선이 먼저 그려진 뒤 3D로 기울어지며 벽과 책상이 솟아오르는 인터랙티브 배치도입니다.
책상을 누르면 자리 주인과 팀·직무가 표시됩니다.

- 파일: `index.html` (브라우저에서 바로 열기)
- 도면 비율: 가로 30 × 세로 20 cm
- 구성: 책상 40석(5개 섬 A~E), 회의실 3, 탕비실 1, 대표이사실 1, 라운지·출입구
- 표기된 이름은 모두 **가명**입니다. (초안)
- 3D 화면은 three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 업데이트 예정
- 이전할 사무실 실제 평면도 반영
- 실명 좌석 배정 반영 → 실명 반영 후에는 저장소를 비공개로 유지하고 외부 공개(GitHub Pages 등)는 하지 않습니다.
